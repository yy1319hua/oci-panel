# Bncr 插件：OCI 面板查询

通过 [Bncr](https://mourgod.github.io/Bncr/) 机器人调用 oci-panel 开放 API，在 QQ / 微信 / Telegram 里查询甲骨文实例状态、流量、成本。

脚本本身**平台无关**（只跟 Bncr 的 `Sender` 抽象打交道），一份代码多平台通用，且**纯只读**，不含任何开关机类写操作。

## 安装

1. 把 `oci-panel.js` 复制到 Bncr 的 `plugins/` 目录
2. 重启 Bncr（或热重载插件）

> ⚠️ **改名时务必同步**：Bncr 要求插件元数据里的 `@name` 必须与**文件名（去掉 `.js` 后缀）完全一致**，否则插件无法被正确识别。
> 例如文件叫 `oci-panel.js`，则注解必须写 `@name oci-panel`；若改成 `OCI面板查询.js`，`@name` 也要同步改成 `OCI面板查询`。

> ⚠️ **头部注解只能用单空格分隔**：`@name` / `@rule` / `@admin` 等字段后**只能有一个空格**，不要用多空格做对齐。Bncr 按单空格切分元数据，多余的空格会被算进字段值里（典型报错就是"加载异常 / name 不一致"）。正确写法：` * @name oci-panel`，错误写法：` * @name        oci-panel`。

## 配置

在 Bncr Web 管理面板 → 插件配置中填写：

| 配置项 | 说明 |
|---|---|
| 面板地址 | 如 `https://oci.158088.xyz`，结尾不要带斜杠 |
| API Token | 面板 → 系统设置 → API Token 生成 |
| 默认配置ID | 留空则自动取第一个配置；发 `oci 配置` 可查所有 ID |
| 超时（秒） | 默认 30。流量接口实时查询较慢，首次可能需调大 |

## 命令

> 🔒 插件设为 `@admin true`，**仅管理员可触发**，其他人发送命令不会响应。

| 命令 | 说明 |
|---|---|
| `oci` / `oci 状态` | 全部实例概况（状态 / 形状 / 公网 IP） |
| `oci 流量` | 本月流量与免费额度占比 |
| `oci 成本` | 近 30 天成本 |
| `oci 配置` | 查看配置 ID |
| `oci 帮助` | 显示帮助 |

流量和成本支持追加配置 ID，例如 `oci 流量 abc123`；不填则用插件配置里的默认 ID。

## ⚠️ Token 权限注意

面板的 API Token 分两种 scope：

- `readonly` —— 仅允许 GET，**只能查状态**
- `full` —— 可用 POST，查流量 / 成本需要它

因为 `/api/oci/traffic/monthly` 与 `/api/oci/traffic/cost` 是 POST 端点，用 readonly Token 调用会返回 403，此时脚本会提示「需要 full 权限的 Token」。

脚本不做任何写操作，因此即便使用 full Token 也不会误触开关机；唯一风险是 Token 泄露，建议设置过期时间。

## 调用的 API

| 端点 | 方法 | 用途 |
|---|---|---|
| `/api/bot/summary` | GET | 全部配置 + 实例概况 |
| `/api/oci/traffic/monthly` | POST | 月度流量 |
| `/api/oci/traffic/cost` | POST | 每日成本 |

鉴权统一走 `Authorization: Bearer <token>` 请求头。

# 日报推送插件：oci-daily-report.js

每天定时把**成本 + 流量**汇总推送到微信（也可推 QQ / Telegram）。与上面的查询插件互相独立，可同时安装。

## 安装

1. 把 `oci-daily-report.js` 复制到无界的插件目录（同 `oci-panel.js`）
2. 重启无界：`docker restart bncr`
3. 在 Web 面板 → 插件配置里填写下表

> ⚠️ 同样遵守两条规则：`@name` 必须与文件名一致（`oci-daily-report`）；头部注解只能用**单空格**分隔字段。

## 配置

| 配置项 | 说明 |
|---|---|
| **复用插件配置的数据库键** | 默认 `/plugins/凯尼尔/oci-panel.js`。**面板地址和 Token 只从这里读**，插件里没有第二处可填 |
| 配置ID | 留空推送**全部**配置；填写则只推该配置 |
| 推送平台 | 微信填 `wechaty`；TG 机器人 `tgBot`；人形 TG `HumanTG`；QQ `qq` |
| 推送目标：用户ID | 私聊自己填这个；发「我的id」可查看 |
| 推送目标：群ID | 推到群填这个；**填了优先发群** |
| 超时（秒） | 默认 60。配置多时调大 |

### 凭据是怎么复用的

Bncr 把每个插件的配置存在 LevelDB 里，键就是插件路径（如 `/plugins/凯尼尔/oci-panel.js`）。
本插件启动时会去读这个键，按 `表名=完整路径 · 键=userConfig`、`表名=完整路径 · 无键`、
`表名=目录 · 键=文件名` 等几种常见存法依次尝试，**抠出 `panelUrl` 和 `apiToken` 直接用**。

所以只要 `oci-panel.js` 已经配置好，这个插件**什么都不用填**就能跑；换 Token 也只改一处。

> 插件放在别的目录（不是 `凯尼尔`）时，改「复用插件配置的数据库键」这一项即可。
> 本插件**不做任何兜底**：读不到就是键填错了，发「oci 日报 调试」看具体原因。

## 定时怎么设

**方式 A：脚本自带 `@cron`（推荐）**

改脚本头部这一行：

```
 * @cron 0 0 9 * * *
```

六位，含义是「秒 分 时 日 月 周」：

| 表达式 | 含义 |
|---|---|
| `0 0 9 * * *` | 每天 09:00 |
| `0 30 8 * * *` | 每天 08:30 |
| `0 0 9,21 * * *` | 每天 09:00、21:00 各一次 |
| `0 0 9 * * 1` | 每周一 09:00 |

> 如果你的无界要求**五位**（分 时 日 月 周），去掉秒位即可：`@cron 0 9 * * *`。
> 改完**必须重启无界**才生效。

**方式 B：无界自带「定时任务」插件（兜底）**

若平台不认 `@cron`，用无界官方的定时任务插件，定时向机器人发送命令 `oci 日报` 即可，插件会照常响应。

## 手动触发

对机器人发：

- `oci 日报` —— 按插件配置推送（全部配置或指定配置）
- `oci 日报 abc123` —— 临时只看某个配置
- `oci 日报 调试` —— 查看凭据从哪读来的、推送目标是谁（Token 只显示前 6 位）

> 装好之后**先发一次 `oci 日报 调试`**：如果显示「读取结果 ✅ 成功」，说明 Token 复用成功；
> 显示 ❌ 则把错误信息发我，基本能一轮定位。

## 推送目标怎么拿

用另一个微信对机器人发 **`我的id`**，机器人会返回你的 ID，填进「推送目标：用户ID」。群 ID 同理，在群里发或看无界日志。

> 定时推送**必须**填用户ID 或群ID 中的至少一个 —— `@cron` 触发时没有"来源会话"，不指定目标就推不出去（只会写日志）。手动发命令时可以不填，会直接回你当前会话。
